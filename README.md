# G-Coder
A Python class useful for generating g-code for pen plotters.

## Class Features
The following are some of the methods of the GCoder class. These write g-code commands to the output g-code file.
* `add_comment`
* `penup`
* `pendown`
* `move_to`
* `draw_path`
* `wait`
